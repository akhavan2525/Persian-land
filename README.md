# سرزمین پارسیان

بازی استراتژی هم‌زمان (به سبک «قلعه» / Stronghold) با گرافیک سه‌بعدی، ساخته‌شده با **Godot 4.3** برای اندروید (افقی، لمسی).

نبرد ایران و توران از روزگار شاهنامه: دژ ایران را بساز و ارتقا بده، اقتصاد راه بینداز (چوب، سنگ، غذا، طلا)، سپاه گرد آور، روستاهای میانه را از دیوان پس بگیر و دژ افراسیاب را فروریز.

## چه چیزهایی در این نسخه هست

- **یک مرحله‌ی کامل**: نقشه‌ی ۱۶۰×۱۶۰ متری با دریاچه، جنگل سرو، صخره و کوه‌های دور نقشه
- **ساختمان‌ها**: دژ (۳ سطح ارتقا)، خانه با بادگیر، مزرعه‌ی گندم، هیزم‌شکن، معدن سنگ، سربازخانه، برج تیرانداز، دیوار سنگی، دروازه
- **سپاه**: نیزه‌دار، کماندار، اسوار، جاویدان، و پهلوانان (رستم با گرز گاوسر، افراسیاب)
- **دشمن**: دژ دیواردار توران، حمله‌های پیاپی که بزرگ‌تر می‌شوند، تصرف روستاها، سه سطح سختی
- **دیوها** نگهبان روستاهای میانه‌اند؛ گرفتن روستا مرز و درآمدت را بیشتر می‌کند
- **رابط فارسی راست‌به‌چپ** با فونت وزیرمتن و لاله‌زار، نقشه‌ی کوچک، راهنما

## کنترل‌ها

| کار | لمسی | کامپیوتر |
|---|---|---|
| جابه‌جایی دوربین | کشیدن یک انگشت | کشیدن با کلیک |
| زوم | دو انگشت | چرخ موس |
| انتخاب سرباز | زدن روی آن (دو بار = همه‌ی هم‌نوعان) | کلیک |
| انتخاب گروهی | دکمه‌ی «کادر انتخاب» و کشیدن | همان |
| حرکت / حمله | زدن روی زمین / روی دشمن | کلیک |
| ساختن | دکمه‌ی پایین ← جای آن ← «ساختن» | همان |

## جایگزینی مدل‌ها با مدل‌های سه‌بعدی (مثلاً از Meshy)

همه‌ی مدل‌ها فعلاً موقت و ساخته‌شده با کدند. کافی است فایل GLB را با این نام‌ها در پوشه‌ها بگذارید تا خودکار جایگزین شوند (اندازه خودکار تنظیم می‌شود):

```
assets/models/units/<نوع>_<طرف>.glb      یا   assets/models/units/<نوع>.glb
assets/models/buildings/<نوع>_<طرف>.glb  یا   assets/models/buildings/<نوع>.glb
```

- نوع واحد: `spear` `archer` `cav` `immortal` `hero` `div`
- نوع ساختمان: `keep` `house` `farm` `woodcutter` `quarry` `barracks` `tower` `wall` `gate` `village`
- طرف: `iran` `turan`
- مدل رو به جهت ‎-Z بایستد و پایش روی Y=0 باشد.
- اگر مدل انیمیشن داشته باشد، انیمیشن‌هایی که نامشان شامل `idle`، `walk`/`run` و `attack` است خودکار پخش می‌شوند.

## ساخت فایل APK

۱. Godot 4.3 و قالب‌های خروجی (Export Templates) را نصب کنید.
۲. پروژه را باز کنید و از منوی Project ← Export گزینه‌ی Android را بزنید.

تنظیمات خروجی در `export_presets.cfg` است (arm64 و armv7، افقی، تمام‌صفحه).

## ساختار کد

```
scripts/app.gd            تنظیمات سراسری و پوسته‌ی رابط (autoload)
scripts/game/defs.gd      همه‌ی عددها و نام‌های فارسی بازی (برای تنظیم توازن)
scripts/game/world.gd     مرحله: اقتصاد، مسیریابی، ورودی لمسی، برد و باخت
scripts/game/enemy_ai.gd  فرماندهی توران
scripts/world/            زمین، ساختمان، سرباز، دوربین، مدل‌ها
scripts/ui/               منوی اصلی، رابط بازی، نقشه‌ی کوچک
```
